# NEXUS — мониторинг системы на WinUI 3

Десктоп-приложение для Windows, которое показывает состояние компьютера в реальном времени и ведёт журнал событий.

**Стек:** C# · .NET 8 · WinUI 3 (Windows App SDK) · XAML · LibreHardwareMonitor · SQLite

> Статус: ранняя версия (v0.0.7), проект в разработке.

## Что умеет

- **Dashboard:** загрузка CPU, использование RAM, заполненность диска C:, время работы системы
- **Датчики:** температура процессора, данные видеокарты, состояние SSD (ресурс, прочитано и записано) через LibreHardwareMonitor
- **Процессы:** список запущенных программ
- **Бортовой журнал (Logbook):** события пишутся в локальную базу SQLite, есть история и поиск по журналу
- Название процессора и версия Windows определяются автоматически

## Как устроено

| Файл | За что отвечает |
| --- | --- |
| `MainWindow.xaml` | Интерфейс: навигация по разделам, карточки показателей |
| `MainWindow.xaml.cs` | Обновление показателей CPU, RAM, диска, датчиков |
| `SystemMonitorService.cs` | Фоновые таймеры: отслеживание процессов и окон |
| `LogService.cs` | Работа с SQLite: создание таблицы `LogEvents`, запись и чтение событий |

База журнала хранится в `%LocalAppData%`, файл `nexus.db`.

## Запуск

Нужны Windows 10/11, Visual Studio 2022 с нагрузкой «Разработка приложений WinUI» и .NET 8 SDK.

1. Открыть `NEXUS.slnx` в Visual Studio
2. Выбрать конфигурацию `x64` и запустить (F5)

Для чтения части аппаратных датчиков (температура, SMART) может понадобиться запуск от имени администратора.
